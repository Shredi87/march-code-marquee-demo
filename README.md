# Исходная и исправленная анимация.

Отдельный проект на Next.js 16.1.6, React 19.2.4 и Tailwind CSS 4.2.1.
На одной странице расположены две версии блока с https://march-code.ru/o-nas.
Используются тот же список технологий, цвета, размеры и шрифт Manrope.

## Запуск

```sh
npm install
npm run dev
```

Открыть http://localhost:3030.

Сборка и запуск собранной версии:

```sh
npm run build
npm start
```

Собранная версия запускается на http://localhost:3107.

## Две реализации

- `components/tech-stack.jsx`: общая разметка блока и исходная строка. В ней намеренно сохранены две копии списка, `gap: 12px`, движение на `-50%`, периоды 40 и 46 секунд. На широких экранах возникает пустота, на стыке — смещение на 6 px.
- `components/adaptive-marquee.jsx`: исправленная строка. `ResizeObserver` измеряет контейнер и одну группу. Количество повторов покрывает видимую область при любой фазе движения. Последний отступ входит в ширину группы; CSS-анимация сдвигает ленту ровно на эту ширину. Скорость задаётся в пикселях в секунду. Изменение ширины окна добавляет или удаляет копии без перезапуска анимации.
- `app/globals.css`: стили и обе CSS-анимации. При `prefers-reduced-motion` исправленный вариант показывает все технологии неподвижно с переносом строк. Дубликаты исключены из дерева доступности.

Шрифт сохранён локально из публичного оформления исходного сайта, поэтому сборка не требует доступа к Google Fonts. Других библиотек анимации нет.
